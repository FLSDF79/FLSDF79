## Projeto público principal

### compound-skills

[https://github.com/FLSDF79/compound-skills](https://github.com/FLSDF79/compound-skills)

Um sistema de melhoria governada de skills para agentes de IA.

Características principais:

- Medição de novidade para decidir entre aprofundar skill existente ou criar nova
- Orçamentos e tetos rígidos para evitar proliferação descontrolada de contexto
- Testes de regressão para validar gatilhos antes de publicação
- Mecanismos de backup, diff e rollback para reversibilidade
- Sanitização automatizada para padrões de segredos e dados pessoais
- Ciclo de vida com data de revisão obrigatória

A release v2.2.0 está disponível publicamente, com pipeline de CI validado.

O projeto aplica uma ideia simples: automação responsável precisa de limites, validação e reversibilidade.

## Frentes de atuação

- **IA aplicada à gestão:** uso de modelos e ferramentas para apoiar decisões, reduzir trabalho repetitivo e melhorar a qualidade de entregas.
- **Automação responsável:** soluções que priorizam rastreabilidade, auditabilidade e ausência de atalhos que comprometam segurança ou privacidade.
- **Produtividade e conhecimento:** construção de sistemas pessoais de organização que escalam com o profissional, não contra ele.
- **Governança de tecnologia:** integração de considerações éticas, de compliance e de longo prazo em todas as implementações.

## Princípios

- Evidência e utilidade antes de promessas ou complexidade.
- Segurança e privacidade como requisitos não negociáveis.
- Documentação que permite reprodução e crítica.
- Melhoria contínua com mecanismos de reversão.
